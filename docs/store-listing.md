# Тексты для магазинов

Готовые куски для Chrome Web Store и Microsoft Store. Правьте свободно, но
обоснования разрешений менять осторожно — их читает проверяющий.

## Chrome Web Store

**Название:** IPasswrd

**Краткое описание (до 132 символов):**
Автозаполнение паролей, ключи доступа и коды проверки из вашего сейфа IPasswrd. Всё хранится только на вашем компьютере.

**Полное описание:**

IPasswrd — менеджер паролей, который держит ваш сейф на вашем компьютере, а не на
чужом сервере. Это расширение — его рука в браузере.

Что оно умеет:
• подставлять логин и пароль на сайтах, где у вас есть запись в сейфе;
• предлагать сохранить новый пароль, когда вы регистрируетесь;
• работать с ключами доступа (passkey) — вход без пароля вообще;
• подставлять коды двухфакторной проверки, не заставляя лезть в телефон;
• подхватывать код из СМС, пришедшей на ваш айфон, прямо на компьютере.

Расширение не хранит паролей и не ходит в интернет. Оно разговаривает только с
приложением IPasswrd на этом же компьютере. Без установленного приложения работать
не будет — скачать его можно на github.com/yoyololka/ipasswrd

Ни аналитики, ни телеметрии, ни рекламы. Исходный код открыт.

**Категория:** Productivity / Workflow & Planning

**Политика конфиденциальности:** https://yoyololka.github.io/ipasswrd/privacy.html

### Обоснования разрешений (проверяющий их читает — отвечайте прямо)

**nativeMessaging** — единственный способ, которым расширение получает данные:
локальный обмен с приложением IPasswrd на том же компьютере. Никакого другого
источника у него нет.

**storage** — хранит только состояние сессии: заблокирован сейф или нет. Пароли
в хранилище расширения не попадают.

**host_permissions: http://127.0.0.1/** — запасной канал к тому же локальному
приложению, когда native messaging недоступен. Это петлевой адрес, наружу он не
выходит.

**Доступ ко всем сайтам (content scripts)** — поля для входа бывают на любом
сайте, заранее список составить нельзя. Скрипт смотрит на адрес страницы, чтобы
подобрать нужную запись, и заполняет поля по вашей команде. Содержимое страниц
никуда не передаётся и не сохраняется.

**Удалённый код** — не используется. Всё выполняемое лежит в пакете.

## Microsoft Store

**Название:** IPasswrd

**Краткое описание:**
Зашифрованный менеджер паролей для Windows. Сейф остаётся на вашем компьютере.

**Обоснование ограниченного разрешения unvirtualizedResources** (его спросят
при отправке — отвечать так):

Приложение — менеджер паролей. Его зашифрованный сейф лежит в
%LOCALAPPDATA%\IPasswrd и должен быть виден в этом же месте другим частям
продукта: расширению для браузера, работающему через локальный мост, и
синхронизации с облачным хранилищем пользователя. Если оставить виртуализацию
файловой системы включённой, запись уйдёт в частное хранилище пакета, и
пользователь, уже имеющий сейф, откроет приложение и увидит пустоту. По той же
причине нужна невиртуализованная запись в реестр: там регистрируется
native-messaging хост, и браузер обязан его увидеть.
