Пароли, которые читаете только вы

Локальный менеджер паролей с оконечным шифрованием. Пароли, коды 2FA, банковские карты, документы и ключи доступа — в зашифрованном сейфе у вас на устройстве. Без серверов, без слежки.

Почему безопасно

  • Оконечное шифрование. Ключ выводится из вашего мастер-пароля (Argon2id), данные закрыты AES-256-GCM. Мастер-пароль нигде не хранится.
  • Нет серверов — нет утечки. У приложения нет облака, которое видит ваши данные. Нет мастер-ключа и нет бэкдора.
  • Украденный файл бесполезен. Перебор мастер-пароля намеренно замедлен Argon2id; ключ шифрования защищён даже в оперативной памяти и стирается при блокировке.
  • Никакой слежки. Ни аналитики, ни телеметрии, ни рекламы, ни продажи данных.
  • Проверено атакой. Перед выпуском приложение прошло состязательный аудит безопасности (red team): всё найденное устранено и перепроверено.

Честно о границах: как любой серьёзный менеджер паролей, IPasswrd рассчитывает на надёжный мастер-пароль и незаражённое устройство. Всё остальное закрывает математика, а не обещания.

Что умеет

Автозаполнение в браузере

Фирменное расширение подставляет логин и пароль прямо в поля — минуя буфер обмена. Несколько аккаунтов на сайт, карты и анкеты.

Ключи доступа (passkey)

Вход без пароля на поддерживающих сайтах. Приватный ключ создаётся и хранится в зашифрованном сейфе и не попадает в страницу.

Встроенный аутентификатор

Коды 2FA (TOTP) рядом с паролем, с автоподстановкой кода после входа.

Проверка на утечки

Пароли сверяются с базой Have I Been Pwned по k-анонимности — сам пароль никуда не отправляется.

Генератор и Windows Hello

Надёжные пароли в один клик. Быстрая разблокировка по лицу, отпечатку или PIN — ключ заперт в чипе TPM.

Синхронизация — по желанию

Между устройствами через ваш iCloud Drive или Google Drive: в облако уходит только зашифрованный файл.

Установка

  1. Скачайте установщик кнопкой выше.
  2. Запустите IPasswrdApp-win-Setup.exe. Windows SmartScreen может предупредить о неизвестном издателе — «Подробнее» → «Выполнить в любом случае».
  3. Придумайте мастер-пароль — и сейф готов. Обновления прилетают сами.
